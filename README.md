## 🌐 独立网页应用 - 无需开发工具

这是一个完整的、独立运行的Web应用，可以直接在浏览器中使用，无需Claude Code或其他开发工具。

### 🎯 快速开始使用

**最简单方式：**
1. 双击 `快速访问指南.html` 文件
2. 选择"直接打开网页版"
3. 开始使用！

**或者直接访问：**
- 打开 `dist` 文件夹
- 双击 `index.html` 文件
- 浏览器会自动打开完整的测评系统

**启动本地服务器（推荐）：**
- 双击 `start-preview.bat` 文件
- 或者运行 `npm run preview`
- 访问 `http://localhost:4173`

## 🚀 部署指南

### 方式一：本地使用（推荐个人使用）

1. **直接打开HTML文件**
   ```
   打开 dist 文件夹 → 双击 index.html
   ```

2. **使用预览服务器**
   ```bash
   npm run preview
   # 访问 http://localhost:4173
   ```

3. **使用启动脚本**
   ```
   双击 start-preview.bat 文件
   ```

### 方式二：云端部署（推荐团队使用）

#### 免费部署（推荐）

**Vercel（最简单）**
1. 访问 https://vercel.com
2. 注册/登录账号
3. 点击 "New Project"
4. 选择 `dist` 文件夹
5. 点击 "Deploy"
6. 获得免费域名：`https://your-project.vercel.app`

**Netlify**
1. 访问 https://www.netlify.com
2. 拖拽 `dist` 文件夹到网页上
3. 自动获得免费域名

**GitHub Pages**
1. 推送代码到GitHub
2. 仓库设置启用 Pages
3. 选择 `dist` 文件夹
4. 访问 `https://username.github.io/repo/`

#### 付费部署（企业推荐）

- **阿里云OSS + CDN** - 国内访问快
- **腾讯云COS + CDN** - 服务稳定
- **AWS S3 + CloudFront** - 全球分发
